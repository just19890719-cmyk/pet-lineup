# 萌寵排排站

可愛動物排序益智遊戲，用 Godot 4.7 製作。

## 直接玩

手機或電腦用瀏覽器打開就能玩，不用安裝：

**https://just19890719-cmyk.github.io/pet-lineup/**

## 玩法

- 點一欄，拿起最上面同一種的動物，再點另一欄放下。
- 只能放到空欄，或是最上面是同一種動物的欄。
- 同一種動物排滿一整欄就會消除，全部消完就過關。
- 問號方塊要等上面的動物移走才會翻開。
- 卡住時可以把動物先放到下面的暫存格，或按「撤回」。

## 開發

- 用 Godot 4.7.2 開啟 `project.godot`。
- 網頁版在 `docs/`，由「Web」匯出設定產生。
- 字型為思源黑體（Noto Sans TC）的精簡版，授權見 `assets/fonts/OFL.txt`。
- 美術圖由 AI 生成。
