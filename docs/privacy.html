萌寵排排站 隱私權政策

生效日期：2026 年 11 月 15 日

一、我們是誰

萌寵排排站（英文名稱 Pet Lineup，以下稱「本遊戲」）由 Luca studio 提供。對本政策有任何問題，請來信：kpyluca.studio@gmail.com。

二、先說重點

  • 本遊戲不需要註冊帳號，我們不收集你的姓名、電話、電子郵件或通訊錄。
  • 你的遊戲進度只存在你的裝置上，不會上傳給我們，我們沒有伺服器保存玩家資料。
  • 本遊戲不使用相機、相簿、麥克風、定位或通訊錄，不會向你要求這些權限。
  • 手機版有廣告。廣告由谷歌的行動廣告服務提供，它會收集一些裝置與使用資料（詳見第四節）。
  • 我們沒有要求「追蹤」的權限，廣告不會用你在其他公司的應用程式或網站上的活動來針對你。

三、留在你裝置上的資料

  • 遊戲進度：你玩到第幾關、目前這一關玩到一半的盤面、是否看過新手教學。
  • 設定：你選的語言、音效與音樂的開關。
  • 購買狀態：是否已購買「免廣告」。

這些資料只存在你的裝置上，用來讓遊戲正常運作，我們看不到，也拿不到。

四、廣告

手機版有兩種廣告：

  • 獎勵式廣告：只有在你自己選擇看廣告來換取撤回次數、翻開問號、提示或多一格暫存格時才會播放。
  • 過關廣告：在兩關之間播放，不會在你玩到一半時跳出。

購買「免廣告」後，不會再有任何廣告。

廣告由 Google LLC 的行動廣告服務（Google AdMob）提供。播放廣告時，該服務可能會收集並處理下列資料：

  • 網路位址，並用它推估大略的所在地區（例如國家或城市）
  • 裝置資訊，例如機型、作業系統版本、語言、螢幕大小
  • 裝置識別碼（用於計算廣告次數與防止詐欺）
  • 廣告相關的操作，例如廣告是否顯示、是否看完、是否點選
  • 應用程式的執行狀況與診斷資料

這些資料用於提供與衡量廣告、防止詐欺與濫用、改善廣告服務。本遊戲沒有向你要求「追蹤」的權限，所以廣告服務不會取得你的廣告識別碼，廣告以不針對個人的方式提供。

谷歌如何使用這些資料，請見：谷歌如何使用合作夥伴網站或應用程式的資訊、谷歌隱私權政策。

我們不會把你的遊戲進度交給廣告服務。

五、購買

「免廣告」是一次性的應用程式內購買，由蘋果公司處理付款。我們不會收到你的信用卡號、付款方式或蘋果帳號資料，只會從系統得知「這支裝置是否已購買」。購買紀錄與退款請依蘋果的規定辦理。

六、網頁試玩版

本遊戲另有在瀏覽器中遊玩的網頁試玩版。網頁版沒有真正的廣告，也沒有購買功能；遊戲進度存在你的瀏覽器裡。網頁由 GitHub 的網頁代管服務提供，該服務可能會基於安全目的記錄來訪者的網路位址，詳見 GitHub 隱私權聲明。

七、資料保存與刪除

  • 刪除本遊戲會一併刪除裝置上的遊戲進度與設定，且無法復原。已購買的「免廣告」可以用「恢復購買」取回。
  • 我們沒有你的資料備份；更換手機時，遊戲進度不會自動跟著移轉。
  • 由廣告服務收集的資料，依谷歌的政策保存與刪除；我們無法代為查詢或刪除。

八、兒童

本遊戲不是專為兒童設計，也不會刻意收集兒童的個人資料。未滿 13 歲（或你所在地區規定的年齡）的兒童，請由家長陪同並同意後使用。

九、你的權利

依中華民國《個人資料保護法》及你所在地區的法律，你可能有權查詢、更正、刪除你的個人資料，或反對特定的處理方式。因我們不在伺服器保存你的個人資料，通常沒有資料可供查詢；與廣告有關的資料請向谷歌提出。如有疑問歡迎來信。

十、政策變更

本政策如有修改，會更新本頁並修改生效日期；重大變更會在本遊戲內通知。
